# Owner playtest — 2026-09-03

These are observed defects and requested outcomes from the live native owner
session. A checked item requires an automated contract plus the native visual
gate where presentation is involved.

The owner's Diablo II: Resurrected screenshots and the design principles they
establish are archived in
[`docs/reference/diablo-ii-resurrected/`](../../docs/reference/diablo-ii-resurrected/README.md).
Use that reference for the intended character-selection staging, world-first
town composition, sculptural resource orbs, compact action belt, and restrained
edge UI. It is a quality/composition benchmark, not a source of assets to copy.

## Blocking correctness

- [x] Full native server restart preserves House/Scion state, currency,
  equipment, builds, bank and House investment in the new disk-backed server.
  A real-process abrupt-restart regression also covers reserve Scions, final
  death and relic recovery. See [restart evidence](restart-save-2026-09-04.md)
  for coverage and remaining migration/multiplayer limitations.

- [x] Returning to town must preserve the active Scion's coins, backpack,
  equipment, stats, and quest state. The observed build emptied both weapon and
  purse, preventing attacks and vendor testing.
- [x] Re-entering a route must create a fresh instance. Dead-monster telegraphs
  and already-collected gold-rarity loot reappeared on repeat entry.
- [x] No combat telegraph, enemy effect, ground loot, or instance EXIT may leak
  into town.
- [x] A safe return must arrive at the Crossroads fountain, not restore the
  remote road-gate departure coordinate.
- [x] Prove collect -> return -> buy -> equip -> re-enter end to end.

## Interaction and combat

- Replace debug `N` travel with clickable world portals. Hover uses a clear
  white selection outline; clicking enters without a confirmation window.
- [x] Town NPCs open through direct click while town attacks are disabled.
- [x] Loot is clickable by object/filter position. Keep `X` as the
  nearest-item alternative and `Z` as label toggle.
- [x] Thrust and Sweep visibly fired, but cooldown state was not readable. Use an
  icon-local radial clock wipe and a restrained ready pulse.
- Warcry is unlockable, not a default binding. Do not show unavailable skills
  as apparently ready. Bindings are selected from the current Scion's unlocked
  skills for LMB, RMB, Q, E, R, and T.
- [x] Enemy telegraphs use true transparency over terrain; Warden safe eyes
  remain unpainted. Pixel-level regression and production capture verified.
- [x] Blank inventory clicks cannot equip the last selected item. Clicks use
  painted footprints and stable UUIDs, including across snapshot reordering.
- [x] Character/journal mouse clicks no longer attack behind their panes;
  right-click dashes respect pane boundaries.

## Major surfaces

- The large `Tab` map should be a transparent world-edge overlay, not an opaque
  window that hides play. Integrate the small minimap into the HUD language.
- Inventory is the WIZARD RPG composition: right-side pane, equipment ragdoll
  above, large backpack below, real item art, and conditional left-edge tabs
  for attendants, trophies, reagents, and expanded storage.
- Character/stats uses the left half and can coexist with inventory. Remove the
  current redundant stat/House/debug text from inventory.
- The owner-supplied dual-pane reference makes this composition explicit:
  left character/attendant pane, right equipment-and-backpack pane, visible
  carried gold, common Framekit grammar, and a live-world channel left open
  between them. Treat its spatial hierarchy as an acceptance reference.
- The geometric WIZARD skill tree is full-screen and only opens in safe areas.
  Inventory and character panes may layer over it for live equipment/stat
  comparison.
- Surface unspent skill points above the experience rail.

## UI and text polish

- [x] Replace `connection connected` with a compact healthy-network icon;
  reserve text for reconnecting/offline states.
- [x] Increase spacing between `VERDIGRIS` and `CHRONICLES / HOUSE & SCION`.
- [x] Replace the stretched pane-center raster with a seamless dark-stone tile
  while preserving the Framekit brass nine-slice border.
- [x] Item descriptions no longer show UTF-8 mojibake (accented-A punctuation
  sequences). Render supported Unicode or use deliberate ASCII separators.
- Make health/mana orbs slightly larger and improve their inner liquid fill.
- Remove the opaque black box around the experience rail.
- Make objective progression notifications materially more visible.
- Show carried gold clearly in town, shop, and inventory contexts.
- [x] Shop rows communicate one item, one price, affordability, and purchase
  result without ambiguous quantity markers.

- [x] Follow-up owner playtest, 2026-09-04: House founding and Scion naming

  into the neighboring action pane. Fit/clip this heading during startup
  streamlining; the corrected editable name field is a separate surface.

- Replace Chronicle-first startup with WIZARD `verdigris_splash`: the real
  floating-island scene, authored motion, drag orbit, zoom, atmosphere, and
  adaptive quality.
- `Enter the World` continues the active Scion (or routes to required setup),
  `Forge a Wanderer` enters Scion creation, and `Read the Chronicle` opens the

  toggle inside Scion creation, one concise permanent-death explanation, and a
  visibly oath-aware admission action. Do not add a separate mode page or
  confirmation maze.
