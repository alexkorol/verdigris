All frames are 96x96 RGBA, anchor [48,80], 48px/metre. Source pixels are reconstructed on the inferred 4x lattice without per-frame resizing or recentering. Female source row2 was uniformly 8px too high: a single recorded integer row translation restores it, and transitions across the row boundary and loop are measured against the exact Blender poses. Hidden RGB in zero-alpha regions is sanitized by reconstruction; transparent originals must be inspected by alpha-compositing them.
