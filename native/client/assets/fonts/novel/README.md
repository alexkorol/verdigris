# Verdigris Novel

Derived from **Not Jam Novel 16**, by Not Jam, downloaded from the author's
[Not Jam Novel 13/16 page](https://not-jam.itch.io/not-jam-novel-13) on 2026-09-14.
The author's original font and metadata are in `source/`; `CC0.txt` is the
included CC0 1.0 Universal waiver/license, permitting bundling and modification.

`VerdigrisNovel.ttf` preserves the original letterforms and metrics. The local
derivative has a distinct family name and adds smart single/double quote,
nonbreaking-space and soft-hyphen mappings to the family's existing glyphs.
Smart quotes therefore have straight quote shapes. Rebuild with
`python native/tools/prepare-ui-font.py` (fontTools 4.56.0 used).

The supplied reference's font is unidentified. Of the bounded runtime comparison
(Novel 16, Not Jam Serif 11, existing Pixelmix), Novel best retained narrow,
single-pixel, differentiated letterforms. It is finer and more condensed than
the reference and is an approximation, not an identification or owner approval.
