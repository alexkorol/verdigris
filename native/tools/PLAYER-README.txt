VERDIGRIS - Windows native game

Double-click Verdigris.exe in this folder. Keep the complete folder together.
The game opens its title menu and starts its own local server.
Closing the game stops that server. No terminal, build tools, or checkout is needed.

Your House/Scion saves live in profile/saves beside this file.
Normal settings: %LOCALAPPDATA%/Verdigris/settings.ini.
To test with a completely separate profile and settings, run:
  Verdigris.exe --profile "C:\path\to\a\new-review-profile"
The optional --quick flag enters a disposable guest directly for QA.
Session logs are in the selected profile/logs directory.

This is an unsigned local review build, not a public release or installer.
Windows x64 and the Windows .NET Framework 4.x runtime are required.
Use a writable extracted folder. Do not run the executable inside a ZIP viewer.
Move the profile folder separately if keeping review saves across package versions.
Keep the profile folder when updating this installation.
