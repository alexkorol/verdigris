# Original Delaford README feature checklist

This is a preserved historical reference, not current Verdigris product
authority. It is transcribed from commit `c4b02bf` (`Redefine readme`) in the
repository history.

The README defined a checkmark as “the basic foundation is in place”; a
checkmarked item could still be incomplete (its example was an inventory that
only supported weapons).

## Player

- [x] Walking / pathfinding
- [X] Context-menu / Actions
- [ ] Health and stats
- [X] Inventory
- [X] Character wear
- [ ] Your first quest

## User Interface

- [x] Inventory tab
- [ ] Quests tab
- [x] Chatbox (for players and actions)
- [x] Character wear tab
- [x] Overall look & feel

## NPC

- [X] Trading (Shops)
- [ ] Dialog Interaction
- [x] Walking around
- [X] Banking

## Monsters

- [ ] Battle System
- [ ] Looting
- [ ] Spawning

## Networking

- [X] Players see each other
- [X] Non-playable characters
- [ ] Monsters
- [ ] Player trading
- [X] Items

## World

- [X] Respawn system
- [ ] Player versus Player
- [ ] Resource skills
  - [X] Mining
  - [ ] Smithing
  - [ ] Fishing
  - [ ] Cooking

The original README described this as the minimum viable product/alpha
checklist and said that checking every item would make Delaford stable without
breaking changes. The current native reconstitution supersedes that checklist
where it conflicts with the Verdigris constitution.
