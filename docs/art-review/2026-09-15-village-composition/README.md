# Village composition proposal

One imagegen candidate after the owner reduced animation scope and rejected the
previous environment/monster direction. `composition-proposal.png` is the original
generated image. `composition-scale-review.png` is only a nearest-neighbor display
preview, not a reconstructed runtime asset. See `review.json` for observed drift.

The packed Blender scene and `build_guide.py` preserve the editable layout.
`guide-native.png` is the768x512 render at48 horizontal pixels/metre;
`guide-2x.png` is its exact integer enlargement supplied to built-in imagegen.
The call also supplied the approved starter exterior from
`native/client/assets/first-slice/concept/starter-player-exterior.png`, the owner's
pixel-style sheet, and the construction photograph. Exact prompt: `prompt.txt`.
Blender MCP was unavailable; this proposal used local Blender2.91 explicitly.

Construction source: Wolfgang F. A. Lobisser, [EXARC2018/2, Hitzacker longhouse
reconstruction](https://exarc.net/issue-2018-2/ea/construction-bronze-age-longhouse-model).
Article licensed CC BY4.0. Reference photo credit Wolfgang Lobisser; used for
timber/reed/earth construction, not as an in-game texture.

This is a visual direction proposal, not owner-approved art or a playable village.
No creatures were invented in this pass. No production assets were imported.
