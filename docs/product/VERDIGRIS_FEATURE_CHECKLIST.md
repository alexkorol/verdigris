# Verdigris feature checklist (working, incomplete)

This is the current user-authored feature checklist. It is intentionally
incomplete: an unchecked item means “not yet closed as a product requirement
or acceptance test,” not necessarily “nothing exists.” The constitution remains
the authority when a detail is still being resolved.

## Player

- [ ] WASD walking with mouse aiming
- [ ] LMB/RMB actions and Q/E/R skills
- [ ] No context menu in the native control scheme
- [ ] Z toggles the loot filter/item highlight
- [ ] X picks up the nearest item
- [ ] Gold auto-picks up
- [ ] Inventory
- [ ] Stats view
- [ ] Passive skill tree
- [ ] Worn equipment is reflected on the in-world character
- [ ] Loose quest threads guide the player through the campaign

## Houses

- [ ] Meta-progression
- [ ] Passive income
- [ ] Asynchronous trading
- [ ] Currency exchange
- [ ] Campaign-to-endgame duration of roughly 6–30 hours, depending on
      optional branches
- [ ] Persistent Legends mode: a Dwarf Fortress-like simulation of storied
      items and monsters

## UI

- [ ] Pane system supporting character + inventory and trade + inventory
      diptychs
- [ ] Minimap with small side and large overlay modes
- [ ] Minimap options for transparency, zoom, and side placement
- [ ] Consistent visual language across orbs, skill bar, and other UI elements

## Campaign

- [ ] Multizone instance graph spanning several acts
- [ ] Optional branches that expose different league mechanics or unlocks
- [ ] Completion once per House per season

## Monsters

- [ ] Stat symmetry: monsters share player stats and elements
- [ ] Pack spawning, monster rarity, and unique monsters
- [ ] Scarce equipment drops with more generous trophies and crafting
      materials

## World

- [ ] Respawn/permadeath system
- [ ] Persistent Legends: special items and monsters remain in loot and spawn
      pools
- [ ] Fast travel or town portals

## Deliberate follow-up decisions

The checklist still needs decisions on economy rates and sinks, the exact
season reset/inheritance rule, what the Legends simulation records, branch
length targets, fast-travel risk, and the final minimap/pane interaction model.
Those decisions are tracked in
[`OPEN_DECISIONS.md`](OPEN_DECISIONS.md), rather than being silently filled in
with genre defaults.
