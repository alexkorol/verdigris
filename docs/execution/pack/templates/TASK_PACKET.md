# READY packet template — DRAFT until every required field is resolved

## Identity and authority
- Repository TASK ID: NOT_ASSIGNED
- Planning goal / existing-task disposition: NOT_RESOLVED
- State: DRAFT
- Owner / worker / reviewer / integrator: NOT_ASSIGNED
- Exact implementation base / authority hashes: NOT_STAMPED
- Current claim token and ledger revision: NOT_CLAIMED
- Risk/review tier and required owner ruling: NOT_APPROVED

## Outcome
One bounded observable result. State player/system benefit and explicit non-goals.

## Dependencies and interfaces
List integrated task IDs and their integration SHAs. Name frozen input/output contracts, versioned fixtures and public/schema changes. List required decisions separately.

## Ownership and resources
Exact owned files/directories; forbidden paths; public-contract locks; integration reservation; build/capture/log locations; allocated ports; disposable test profile; compute/time limits from the actual execution environment. Candidate paths are not sufficient for READY.

## Acceptance
Provide actual build/test commands, working directory, platform, expected assertions and exit behavior. Explain how new targets are wired without an unowned CMake/CI edit. Name the negative control and its expected failure. State ordinary-play, image/audio or package evidence required.

## Integration and recovery
Name the production caller and integration successor when separate. Define what remains NOT_INTEGRATED. State targeted rollback and any schema/content compatibility or forward-recovery constraints.

## Stop conditions
Ambiguous authority; stale/revoked claim; unavailable accepted dependency; path/resource collision; undefined behavior; real-data destructive testing; repeated failures; oversized outcome.

## Report requirements
Base/head; changed paths; actual commands/exits; assertions and negative-control result; build/content/seed/machine; artifact hashes; manual review; integration state; known limitations; numbered questions.

The coordinator/spec owner removes every NOT_* placeholder through current-base validation before READY. Never supply invented evidence to complete this template.
